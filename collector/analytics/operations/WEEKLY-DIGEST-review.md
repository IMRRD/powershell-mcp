Unknown origin remains unknown, never external users. Installation keys are pseudonymous proxies, not people. A restricted preview on the current dataset may fail its coverage gate; record that failure, not a synthetic production digest.

The state intent file is created exclusively and fsynced **before** SMTP; an unknown SMTP acceptance or process crash means no automatic retry. This is at-most-one submission attempt per week/recipient under a shared filesystem, not exactly-once delivery. Reconcile message acceptance and recipient receipt privately before any manual resend; never delete the intent merely to retry. A read-only preview creates no intent. The timer has no catch-up; missed weeks require separately reviewed replay and audience approval.
