# Security Policy

## Reporting a vulnerability

Please **privately report a vulnerability** through GitHub's private vulnerability reporting form:

https://github.com/IMRRD/powershell-mcp/security/advisories/new

Do not disclose suspected vulnerabilities publicly before a coordinated fix and advisory are available. Include affected versions, reproduction steps, impact, and any suggested remediation. We aim to acknowledge reports within 72 hours and will coordinate disclosure timing and researcher credit.

## Supported versions

Security fixes are released on the latest package line. Users should upgrade to the newest version of `@imrrd/powershell-mcp`; the deprecated `powershell-mcp` package exists only as a compatibility forwarder.
